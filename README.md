# Terrestrial Sink Pressure Assessment

This repository provides reproducible code for constructing long-term terrestrial ecosystem sink benchmarks and assessing industrial emission pressure across four major Chinese urban agglomerations.

The complete analysis code, documentation, expected outputs, and MATLAB figure scripts are available in the [`code`](code/) directory.

## Repository contents

- NEP raster preprocessing and grid alignment
- Temporal completeness assessment
- Long-term terrestrial ecosystem sink benchmark estimation
- Industrial emission pressure-ratio calculations
- Sensitivity analyses
- MATLAB scripts for Fig. 7 and Fig. S1
- Expected-result validation

See [`code/README.md`](code/README.md) for detailed instructions.
